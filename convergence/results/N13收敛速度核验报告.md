# N13 采样达标与训练速度

用四个配对随机种子比较 PER 和均匀有放回回放。每个配置按相同的动作参考、奖励和约束训练 120 万步。
共完成 8 次训练、9,600,000 次仿真交互。
每次训练保留 84 个检查点。固定权重重放了 672 个主窗口，共 11,773,440 个评估时步。评估采用相同的 17,520 点归档主窗口和起止电量 37.5 kWh。

主门槛为全期方差下降 75%。持续达标要求从某个检查点开始，后续所有采样点均达标，并至少有 40,000 步后续观察。区间以该点前一检查点和该点为边界，仅反映采样所见。记录中未能确认持续达标的情况保留为删失。

PER 有 4/4 个种子持续达标，均匀回放有 4/4 个。
4 对种子均可比较首次达标步数。PER 较早 3 对，均匀回放较早 1 对，同一检查点 0 对。均匀减 PER 的平均检查点差为 +2,500 步，累计进程 CPU 时间差均值为 +1.35 秒。
4 对种子均可比较持续达标步数。PER 较早 3 对，均匀回放较早 1 对，同一检查点 0 对。均匀减 PER 的平均检查点差为 -16,500 步，累计进程 CPU 时间差均值为 -93.38 秒。

PER 和均匀回放的平均进程 CPU 时间分别为 2,184.42 秒和 2,075.39 秒。配对节省率的均值为 -5.25%。正值表示 PER 使用较少 CPU 时间。八次训练累计使用 17,039.23 秒进程 CPU 时间。

CPU 计时覆盖训练计算与内存记账，暂停于检查点写入和训练日志落盘。主机并发影响墙钟耗时，逐种子与逐检查点的墙钟值保留在表格中。均匀回放沿用树结构的插入路径和公共的更新后残差计算，所以耗时比较适用于这两份具体实现。

固定权重终点有 8/8 个与既有归档端点复核一致。本次训练与评估共享当前归档主窗口。结果适用于这一数据和配置。历史 Base DQN 属于另一训练配置。旧稿的 18,000 步、40,000 步和约 35% 训练时间节省仍需相应的历史证据。
